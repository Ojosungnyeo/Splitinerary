# 🧳 Splitinerary

> 함께 떠나지만, 모든 순간을 함께할 필요는 없으니까.

**Splitinerary**는 친구들과 함께하는 여행 안에서 각자의 취향과 시간을 존중할 수 있도록 도와주는 여행 계획 서비스입니다.

같이 즐길 일정은 함께 계획하고, 잠시 따로 보내고 싶은 시간에는 각자의 동선을 확인할 수 있습니다. 흩어진 뒤에는 다시 합류할 장소와 일정까지 한눈에 관리할 수 있습니다.

## 🔑 Key Features

### 함께 만드는 여행 일정

여행지와 날짜를 정하고, 동행자를 초대해 하나의 여행 일정을 함께 만들 수 있습니다.

### 각자를 위한 개별 동선

같은 여행 중에도 서로 다른 장소를 방문할 수 있도록 여행자별 동선을 제공합니다.

카드를 좌우로 넘기면 선택한 여행자의 동선만 지도에 표시되며, 카드와 경로는 같은 색상으로 연결되어 누구의 일정인지 쉽게 구분할 수 있습니다.

### 전체 동선 한눈에 보기

전체 동선 보기 기능을 사용하면 모든 여행자의 경로를 하나의 지도에서 동시에 확인할 수 있습니다.

각자의 이동 경로와 목적지를 비교하며 합류 장소나 다음 일정을 더욱 편리하게 계획할 수 있습니다.
